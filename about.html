What I Learned

In this final project, I successfully implemented a multi-page website utilizing external CSS. I practiced semantic HTML, accessible navigation, and modern layout techniques.

Key CSS Features Used:

  • Flexbox: For the responsive top navigation bar.
  • CSS Grid: For the 5-image gallery layout.
  • Box Model: Custom padding, borders, and border-radius on all images and containers.
  • Pseudo-classes: :hover for interactive buttons/images, :focus for the skip link, and :nth-child for alternating grid border colors.
